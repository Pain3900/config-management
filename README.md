# Конфигурационное управление. Вариант 15

Консольный транслятор читает конфигурацию из файла UTF-8 и записывает JSON
в стандартный вывод. Flex выделяет лексемы, GNU Bison разбирает их по грамматике.
Вычисления выполняются при трансляции.

## Сборка и запуск

Нужны компилятор C++17 с поддержкой `std::from_chars` и `std::to_chars` для
дробных чисел, GNU Make, GNU Bison и Flex. Для тестов нужен Python 3.

```sh
make
./run.sh --input examples/audio.cfg
make test
```

`run.sh` сам вызывает сборку при необходимости. `--input` и `-i` задают путь
к входному файлу. `--help` и `-h` выводят справку. `make clean` удаляет
результаты сборки. Компилятор и инструменты можно переопределить переменными
`CXX`, `BISON`, `FLEX` и `PYTHON` в команде `make`.

При успехе программа возвращает код 0. При ошибке чтения, разбора или
вычисления она пишет сообщение в стандартный поток ошибок и возвращает 1.
Для ошибок в конфигурации в сообщении указаны строка и столбец. Неверные
аргументы командной строки дают код 2.

## Синтаксис

| Конструкция | Пример | Правило |
| --- | --- | --- |
| Число | `.5`, `12.75` | `[0-9]*\.[0-9]+`. Числа хранятся как `double`. |
| Строка | `'Это строка'` | Одна строка в одинарных кавычках. Обратная косая черта передаётся буквально. |
| Массив | `{ .5. 'текст'. { 1.0 } }` | Точка разделяет элементы. После последнего элемента точка необязательна. Допускаются вложенные и пустые массивы. |
| Имя | `TEMPO` | Только заглавные латинские буквы по шаблону `[A-Z]+`. |
| Объявление | `TEMPO := 148.0;` | Объявления идут в порядке использования. Повторное объявление одного имени считается ошибкой. |
| Выражение | `![TEMPO 1 +]` | Оператор идёт после операндов. Результат можно использовать в объявлении, массиве или другом выражении. |

Пример в методичке содержит целое `1`. Целые литералы разрешены внутри
`![…]`, а в самостоятельных числах обязательна дробная часть.

`+`, `-` и `*` берут два числовых операнда. Например, `![5 2 -]` даёт
`3`. `sort()` берёт один массив и сортирует числа по возрастанию или строки
лексикографически. Пустой массив остаётся пустым. Для `sort()` все элементы
массива должны быть числами или все должны быть строками. Выражение должно
оставить в стеке ровно одно значение.

Файл с одними объявлениями преобразуется в объект JSON. Если после
объявлений идёт одно итоговое значение, оно выводится напрямую. Объявления
перед ним доступны для вычислений. Пустой файл даёт `{}`.

При подстановке константы, заданной числовым литералом, его исходная запись
выводится как строка JSON. Например, `![TEMPO]` для `TEMPO := 148.0;`
даёт `"148.0"`. В арифметических выражениях такая константа остаётся числом.

## Примеры конфигураций

### Музыка

```sh
./run.sh -i examples/audio.cfg
```

```json
["TEMPO", "148.0"]
```

### Теплица

```sh
./run.sh -i examples/greenhouse.cfg
```

```json
{
  "DELTA": 1.5,
  "HIGHEST": 23,
  "LOWEST": 20,
  "TARGET": 21.5,
  "ZONES": [["рассада", 20], ["томаты", 23]]
}
```

### Доставка

```sh
./run.sh -i examples/delivery.cfg
```

```json
{
  "FEES": [320, 190, 250],
  "ROUTEFEES": [190, 250, 320],
  "ROUTES": ["A", "B", "C"],
  "WAREHOUSE": "Северный склад"
}
```

## Структура проекта

- `src/lexer.l` задаёт лексемы и отслеживает позицию во входном файле.
- `src/parser.y` описывает грамматику, объявления и порядок вычислений.
- `src/config.cpp` хранит константы, выполняет операции и формирует JSON.
- `src/main.cpp` обрабатывает параметры командной строки и открывает файл.
- `tests/test_cli.py` проверяет синтаксис, вложенность, вычисления и ошибки.
- `examples/` содержит входные файлы из трёх предметных областей.
